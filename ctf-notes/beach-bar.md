# TryHackMe: Beach Bar 🏖️

## Challenge Overview

Beach Bar was a hands-on cybersecurity challenge focused on investigating web content and identifying clues hidden within a website.

## Learning Objectives

- Inspect HTML source code.
- Identify clues hidden in HTML comments.
- Investigate playlist import functionality.
- Practice structured web application analysis.
- Document findings clearly.

## Investigation Process

### 1. HTML Source Inspection

Inspected the webpage's HTML source to understand its structure and look for clues that were not immediately visible on the rendered page.

### 2. HTML Comments

Learned that HTML comments can contain useful information for developers but may also unintentionally expose clues or sensitive information.

### 3. Playlist Import Investigation

Investigated the playlist import functionality and followed the clue discovered during the challenge.

### 4. Finding Verification

Connected the discovered clues to progress through the challenge and understand how website content can reveal information.

## Tools and Techniques

- Web browser
- Browser Developer Tools
- HTML source inspection
- Manual web application analysis

## Key Takeaways

- HTML comments are visible in page source and should not contain secrets.
- Website functionality can reveal clues about application behavior.
- Systematic investigation is more effective than random guessing.
- Findings should be verified before documenting them.

## Security Lessons

Developers should avoid placing credentials, secrets, or sensitive information in client-side HTML and JavaScript because users can inspect these resources.

## Reflection

This challenge helped me practice inspecting HTML source code, following website clues, and documenting a web investigation in a structured way.
